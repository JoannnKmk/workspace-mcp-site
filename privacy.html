Kebijakan Privasi

Workspace MCP Servers

Terakhir diperbarui: 18 Oktober 2026

1. Ruang lingkup

Kebijakan ini menjelaskan bagaimana aplikasi OAuth pribadi Workspace MCP Servers memperlakukan data yang diperoleh dari Google API. Aplikasi ini dipakai oleh satu orang, yaitu pemilik akun Google yang memberikan izin.

2. Data yang diakses

Aplikasi mengakses data Google hanya setelah pemilik akun menyetujui izin secara eksplisit. Cakupannya meliputi:

  • Gmail: pesan, label, draf, dan pengaturan dasar
  • Google Drive: berkas dan metadata berkas
  • Google Docs, Sheets, Slides: isi dokumen
  • Google Calendar: kalender, acara, dan ketersediaan waktu
  • Google Forms, Tasks, Contacts, Chat: formulir, tugas, kontak, dan pesan
  • Google Apps Script: proyek skrip, deployment, dan metrik
  • Profil dasar: nama dan alamat email

3. Cara data digunakan

Data hanya digunakan untuk menjalankan fungsi yang diminta pemilik akun dari dalam klien MCP, misalnya membaca email, mencari berkas, atau membuat acara kalender. Data tidak dipakai untuk periklanan, tidak dipakai untuk melatih model, dan tidak dipakai untuk tujuan lain di luar permintaan pemilik akun.

4. Cara data disimpan

Aplikasi berjalan sepenuhnya di komputer pemilik akun. Token OAuth dan data sesi disimpan sebagai berkas lokal di ~/.google_workspace_mcp/credentials/ pada mesin tersebut.

Tidak ada server milik pengembang. Tidak ada basis data pusat, tidak ada telemetri, dan tidak ada salinan data yang disimpan di tempat lain.

5. Berbagi data dengan pihak ketiga

Data Google tidak dijual, tidak disewakan, dan tidak dibagikan kepada pihak ketiga mana pun. Aplikasi tidak mengirim data ke layanan analitik, iklan, atau perantara data.

Pengecualian hanya berlaku bila diwajibkan hukum yang berlaku, atau untuk memenuhi kewajiban keamanan yang sah.

6. Akses manusia

Tidak ada orang lain yang membaca data Google pemilik akun. Pemilik akun adalah satu-satunya pihak yang dapat mengakses mesin tempat data tersimpan.

7. Penyimpanan dan penghapusan

Data tersimpan selama pemilik akun menghendaki. Pemilik akun dapat menghapus seluruh data kapan saja dengan:

  • menghapus berkas di ~/.google_workspace_mcp/credentials/, dan
  • mencabut akses aplikasi di myaccount.google.com/permissions.

Setelah akses dicabut, refresh token tidak berlaku lagi dan aplikasi tidak dapat mengakses data Google.

8. Kepatuhan pada Kebijakan Data Pengguna Google API

Penggunaan data yang diterima aplikasi ini dari Google API akan mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Secara khusus:

  • Data tidak ditransfer ke pihak ketiga, kecuali sejauh diperlukan untuk menyediakan atau meningkatkan fitur yang terlihat oleh pengguna, mematuhi hukum yang berlaku, atau sebagai bagian dari penggabungan atau akuisisi.
  • Data tidak digunakan untuk iklan, termasuk iklan yang dipersonalisasi.
  • Data tidak dibaca oleh manusia, kecuali pemilik akun memberi izin eksplisit untuk kasus tertentu, diperlukan untuk keamanan, atau diwajibkan hukum.

9. Keamanan

Token disimpan di mesin lokal pemilik akun dan dilindungi oleh kontrol akses sistem operasi. Aplikasi meminta cakupan izin seminimal mungkin yang dibutuhkan untuk fungsinya.
