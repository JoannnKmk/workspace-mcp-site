Workspace MCP Servers

Aplikasi OAuth pribadi untuk menghubungkan asisten AI dengan data Google Workspace milik pemiliknya sendiri.

Apa aplikasi ini

Workspace MCP Servers adalah aplikasi OAuth pribadi yang dipakai oleh satu orang, pemilik akun Google-nya sendiri. Aplikasi ini menghubungkan klien MCP (Model Context Protocol) seperti Claude Code dengan data Google Workspace milik pemilik akun, lewat server MCP sumber terbuka workspace-mcp.

Tujuannya sederhana: memungkinkan pemilik akun membaca dan mengelola email, berkas Drive, dokumen, spreadsheet, dan kalender miliknya sendiri dari dalam editor kode, tanpa berpindah aplikasi.

Data yang diakses

Setelah pemilik akun memberi izin, aplikasi dapat mengakses:

  • Gmail - membaca, mencari, menyusun draf, dan mengirim email atas nama pemilik akun
  • Google Drive - membaca dan mengelola berkas milik pemilik akun
  • Google Docs, Sheets, Slides - membaca dan menyunting dokumen milik pemilik akun
  • Google Calendar - membaca dan mengelola acara kalender
  • Google Forms, Tasks, Contacts, Chat - membaca dan mengelola data terkait
  • Google Apps Script - mengelola proyek skrip milik pemilik akun

Bagaimana data disimpan

Aplikasi ini berjalan sepenuhnya di komputer pemilik akun. Token OAuth disimpan sebagai berkas JSON di folder lokal ~/.google_workspace_mcp/credentials/ pada mesin pemilik akun.

Tidak ada server milik pengembang. Tidak ada basis data pusat, tidak ada telemetri, dan tidak ada data yang dikirim ke pihak ketiga. Data Google hanya bergerak antara akun Google pemiliknya dan komputer pemiliknya sendiri.

Siapa yang memakai

Aplikasi ini dipakai oleh satu orang saja, yaitu pemilik akun Google yang memberi izin. Aplikasi tidak dibagikan, tidak dijual, dan tidak menerima pengguna lain.
